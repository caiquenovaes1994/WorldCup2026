# Política de Segurança (Security Policy)

## Versões Suportadas

Abaixo está a tabela de quais versões do nosso projeto recebem atualmente atualizações de segurança.

| Versão | Suportado          |
| -------| ------------------ |
| v1.0.x | :white_check_mark: |
| < 1.0  | :x:                |

## Relatando uma Vulnerabilidade

Levamos a segurança do nosso código muito a sério. Se você descobrir qualquer problema de segurança, por favor, não crie uma issue pública no GitHub. Em vez disso, siga o procedimento abaixo:

1. **Notificação Privada**: Envie um e-mail detalhado sobre a vulnerabilidade para o contato principal (disponível no README).
2. **Avaliação**: Confirmaremos o recebimento do seu relatório em até 48 horas. Faremos uma triagem da vulnerabilidade e determinaremos o impacto.
3. **Correção**: Caso confirmado, trabalharemos o mais rápido possível para providenciar um patch de correção e uma nova versão.
4. **Reconhecimento**: Após a correção pública da vulnerabilidade, daremos os devidos créditos pela sua descoberta, caso você permita.

Por favor, forneça no seu e-mail:

- Uma descrição detalhada do impacto potencial.
- Os passos exatos para reproduzir a vulnerabilidade.
- Se possível, o arquivo/linha de código exato que está afetado.

Obrigado por ajudar a manter nossa plataforma segura para todos os usuários!
